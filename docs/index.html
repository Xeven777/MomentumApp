Features

Everything a habit tracker needs.
Nothing it shouldn’t have.

Every feature below ships in the release build. There is no “plus” tier, because there is no tier.

📋

Habit tracking

Add, edit and delete habits with an emoji, stored in a local Room database. Tap a row to tick it off for the day.

🏠

Smart streaks

Set a daily goal — “3 habits a day”, or all habits by default. A day counts once you hit the goal, and adding a habit never wipes a streak.

📈

Deep stats

Current and best streak, a six-month contribution grid, an eight-week trend, per-habit 30-day completion rates, and badge unlocks.

📅

Scheduled habits

Pick which weekdays a habit applies to. Streaks, reminders and widgets all respect the schedule, so a Mon/Wed/Fri habit never makes a Tuesday look like a miss.

📅

Month calendar

Tap the day strip to expand a full month view with a per-day completion ring. Swipe between months, tap to select a day. Collapsed by default, so it costs no screen space.

📱

Home screen widgets

A progress ring with your streak and today’s completion, plus a 12-week contribution grid. Or a compact 2×2 streak ring. Tap either to open the app.

⏰

Reminders

Per-habit reminder times that re-arm automatically after a reboot, a package update, or a clock and timezone change.

🔒

One-time welcome

A splash with a Get Started button and a name step on first run. After that the app opens straight to your habits.

🔥

Badges

Unlock 3, 7, 30 and 100-day streaks, plus a perfect week, as you go. Progress you can see is progress you keep.

Privacy

Most habit trackers trade your data or your attention. This one doesn’t.

Momentum is offline by default. The single network call in the entire app is the AI request, and only the one you tap.

✕ What Momentum never does

  • ✕Ask you to create an account or verify an email
  • ✕Sync your habits to a server, ours or anyone’s
  • ✕Run analytics, telemetry or crash reporting
  • ✕Show ads, or sell anything to anyone
  • ✕Put a paywall or a subscription in front of you
  • ✕Ship a Firebase or advertising SDK

✓ What it does instead

  • ✓Keeps habits and completions in an on-device Room database
  • ✓Holds the API key encrypted with a key in the Android Keystore
  • ✓Makes zero network calls until you explicitly trigger the AI
  • ✓Is fully MIT licensed, so the code is auditable line by line
  • ✓Covers its streak arithmetic with 47 passing unit tests
  • ✓Ships a 2.9 MB release APK, because nothing extra is bundled

Optional AI assistant

FAQ

Questions people actually ask

If something here is still unclear, the readme has the long version.

Does it work without internet?

Yes, fully. Habits, completions, streaks, stats and reminders all live on your phone, so every core feature works in airplane mode. The only feature that touches the network is the optional AI assistant, and only on the request you trigger yourself.

Do I need an account?

No. There is no sign-up, no email, no verification and no password to forget. Install it and start ticking habits off.

Is it really free?

Yes. Momentum is MIT licensed, with no ads, no subscriptions, no paywalls and no “plus” tier. The full feature set is in the free app.

How is it under 3 MB?

Nothing extra is bundled. There is no Firebase, no analytics and no advertising SDK, and release builds run through R8 minification and resource shrinking. The result is roughly 2.9 MB — smaller than a single screenshot.

Where do I download it?

From the GitHub releases page. You can grab the APK and install it directly, or build it yourself from the source.

What does the AI assistant do, and is it safe?

It is off until you turn it on. You paste your own API key and point the app at any OpenAI-compatible provider, and it suggests habits from a short questionnaire or your own description. The key is encrypted with a key held in the Android Keystore, and it never enters the app build. Skip it entirely and nothing changes.

Can I trust it with my data?

You can read it. The project is open source, so the streak logic and everything else is auditable line by line, and the release build has no telemetry to audit. The core streak arithmetic is covered by 47 unit tests.
